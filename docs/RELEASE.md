# Escapement 1.0.0

Initial public release of the local acoustic workbench and portable Windows x64 application.

- Real sample-clocked microphone input, input selection and actual processing inspection.
- Worker-based pulse detection, BPH candidate scoring, rate, professional half-interval beat error and conditional Swiss-lever amplitude.
- Labeled synthetic audio scenarios through the same engine.
- Trace, waveform, tick/tock views, audio spectrum, history, level and clipping indicators.
- Watch collection, durable sessions, notes, six-position testing and explicit weighted comparisons.
- Observed drift and power-reserve observations.
- Versioned JSON backup, protected CSV export, audio import, opt-in WAV recording, chart PNG and printable reports.
- Audio-clock calibration profiles with independent-reference instructions.
- Offline-installable PWA and repository-subpath deployment.
- Automated engine, persistence, browser and acquisition validation.

Real mechanical-watch recordings, physical pickup behavior and independent reference-instrument comparison remain outside this release's validation evidence. See VALIDATION.md.
